# NovWr Landing 概念图生成简报（供 Codex image generation 使用）

## 产品事实（不可虚构）

- 产品：NovWr（NovelWriter），面向百万字级长篇小说续写的本地写作工具。核心是"世界模型"：
  从正文提取实体（人物 / 地点 / 物品 / 势力）、关系、体系，续写时只注入当前章节需要的设定。
- 三个界面：Studio（写作台）、Atlas（世界地图 / 设定治理）、Copilot（只读研究助手，带出处引用）。
- 五步工作流（i18n 已有文案）：导入 → 基建 → 审核 → 查阅 → 续写。
- 内置示例：《西游记》前二十七回。实体示例：唐僧、孙悟空、猪八戒、沙僧、白龙马、观世音菩萨、
  花果山、五行山、高老庄、如意金箍棒、紧箍咒、天庭、佛门。关系示例：唐僧—孙悟空「师徒」。
  每个属性有"表面 / 真相"两层（读者看到的表面 vs 只有作者知道的真相）。
- 现有 Hero 文案：眉标「超长篇续写引擎」，标题「先理解世界，再写出好故事」，
  CTA「开始写作」。英文标题 "Understand the world first. Write better stories."
- 字体：Outfit Variable（拉丁）+ JetBrains Mono（数据）；中文回退系统字体。
- 现有强调色：periwinkle `hsl(235 74% 62%)` ≈ `#5B6BF0`；深色主题近黑靛蓝 `hsl(233 34% 6%)`。

## 视觉方向（本次重构的设定）

- **画布中性**（参考 openai.com 当前设计语言）：浅色主题纯白纸面 `#FFFFFF` + 近黑墨色文字；
  深色主题纯黑 `#000000` + 白字。灰阶用黑/白的透明度层级（4% / 12% / 44% / 60% / 80%）。
  按钮为 40px 圆角药丸：主按钮纯黑填充白字，次按钮 4% 黑填充。
- **色彩只出现在"媒体框"里**：所有颜色、光效、shader 都被限制在圆角 20px 的媒体框（stage）内，
  框外是安静的纸面和排版。
- **核心视觉概念：「经纬」**——世界模型是故事的经线（warp），百万字正文是纬线（weft）。
  Shader 画的是一张由细线组成的织物 / 星图：散乱的线在滚动 / 时间推进中被拉直、打结成节点，
  节点即实体，节点间的线即关系。浅色主题下是纸上的靛青细线（像蓝图 / 印刷网线），
  深色主题下同一张图读成星图（呼应产品的 Atlas 命名与现有星空主题）。
- **标题排版**：中文大标题用宋体类衬线（文学感），字重 500 左右，行高 1.1，字距 0；
  英文标题 Outfit 500，字距 -0.03em。正文 Outfit / 系统无衬线。数据标签 JetBrains Mono。
- **克制的动效**：只有一次 hero 的"织线成图"入场，以及滚动驱动的舞台切换；没有逐段淡入。
- 避免：紫粉赛博渐变、玻璃拟态卡片堆叠、每张卡都有阴影、全大写眉标、大数字统计行、
  Anthropic 式暖米色 + 陶土色。
